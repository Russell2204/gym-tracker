# IronLog — дневник тренировок

Next.js 14 + SQLite (better-sqlite3) + Tailwind. Регистрация, программы, суперсеты, таймеры, сравнение с прошлой тренировкой, замеры, статистика, календарь.

## Запуск

```bash
npm install
npm run dev
```

Открой http://localhost:3000 и зарегистрируйся. При регистрации автоматически создаётся стартовая программа «Фуллбади · воскресенье» (присед, жим, тяга + подсобка с суперсетом на руки).

## Продакшен

```bash
cp .env.example .env   # и поменяй JWT_SECRET на длинную случайную строку
npm run build
npm start
```

## Где данные

База лежит в `data/gym.db` (создаётся автоматически). Чтобы начать с нуля — останови сервер и удали этот файл.

## Как устроено

- **Сессии** — JWT в httpOnly-куке, проверка в middleware (jose).
- **Мутации** — server actions (`src/lib/actions.ts`), без API-роутов.
- **Сравнение с прошлым разом** — для каждого упражнения подтягивается последняя завершённая тренировка с ним (`src/lib/queries.ts`).
- **Таймер отдыха** — запускается после подхода (в суперсете — после последнего движения связки), в конце тройной сигнал через Web Audio + вибрация на телефоне.
- **Суперсеты** — общая буква A/B/C у соседних упражнений в программе или галочка «суперсет с предыдущим» при добавлении упражнения в тренировку.

## Структура

```
src/lib       — db, auth, queries, server actions
src/app       — страницы (App Router)
src/components — клиентские компоненты (сессия тренировки, календарь, графики…)
```
